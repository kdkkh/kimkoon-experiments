## 쓰는 법

- 폴더마다 **그 폴더만 떼어 가도 돌아가게** 만들었습니다(다른 폴더에 기대지 않음). 각 폴더의 `README.md` 에 실행 명령이, `AGENTS.md` 에 AI(에이전트)에게 읽히기 위한 지도가 있습니다.
- 직접 읽기보다 쓰시는 AI 에게 폴더를 주고 "`AGENTS.md` 와 `README.md` 를 읽고 네트워크 없이 견본 실행을 돌려 줘"라고 시키는 쪽을 전제로 썼습니다.
- Python 3.11 에서 시험했습니다. 두 폴더 모두 **네트워크 · 키 없이** 도는 견본 실행이 있습니다.

## 들어 있지 않은 것

- 앱키 · 계좌 같은 설정값 — 각자 발급받아 저장소 **밖**에 둡니다.
- 실제 데이터(시세 · 공시 원문 · 뉴스 제목) — 약관상 다시 나눠 줄 수 없어, 형식만 같은 **가짜 견본**을 넣었습니다. `sample_data/` 의 회사 · 종목 · 숫자는 모두 지어낸 것입니다.
- 실전 주문 경로.
